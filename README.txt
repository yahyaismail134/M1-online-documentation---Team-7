M1 — The Radio's Tuner & Detector

OPENING THE WEBSITE
1) Easiest: open index-standalone.html in Chrome or Edge. It includes the video and images inside one HTML file, so no assets folder is needed.
2) For hosting/editing: open index.html with the complete assets folder kept beside it. Do not move index.html out of this folder.

VIDEO
The web video is re-encoded as H.264 Baseline + AAC with fast-start metadata for wider browser compatibility. A poster image and direct-open/download fallback are included. The original uploaded MP4 is also retained as lab-experiment.mp4.

PHOTOS
The oscilloscope and coil photos are still frames extracted from the team's uploaded laboratory video. The other images are original supplied handout/reference scans.

All experimental values are preserved from the supplied tables.
